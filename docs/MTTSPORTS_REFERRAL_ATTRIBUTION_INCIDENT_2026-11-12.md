# MTT SPORTS: успешный Telegram one-tap, но реферал не зачтён

**Дата:** 2026-11-12. **Контур:** Baby MTT / GiftMutant staging. **Статус:** подтверждён механизм разрыва referral/SSO; серверное событие атрибуции не доступно.

## Наблюдение и границы доказательств

- Пользователь вручную протестировал отдельный Telegram-аккаунт: прямой Play Now открыл именованное MTT SPORTS Mini App и автоматически создал/открыл игровой профиль.
- В партнёрском кабинете пользователя список «Моё приглашение» пуст, показано нулевое вознаграждение.
- Нельзя по одному нулевому доходу считать реферальную связь отсутствующей: комиссии могут возникать только при определённых расходах приглашённого.
- Но пустой список вместе с отсутствующим кодом в исходном Play Now является сильным свидетельством неправильного порядка онбординга.
- Не сохранены логины, Telegram IDs, игровой JWT, cookies, Yaako OTP и приватные ключи.

## Аудит точных URL

1. Ссылка, которую сама MTT SPORTS отображает для владельца: `https://mtt.xyz/?i=ba434b5a`.
2. Публично наблюдавшийся Play Now: `https://t.me/MTTSPORTS_bot/MTTSPORTS?startapp=eyJwYXRoIjoiLyIsInBhcmFtcyI6e319`.
3. После декодирования: `{"path":"/","params":{}}`. **Реферальный код `ba434b5a` отсутствует.**
4. Публичный JS MTT SPORTS от 2026-11-12 формирует QR и ссылку приглашения по шаблону `https://${host}?i=${invitationCode}`: модули `lobby_invite` и `lobby_inviteQRCode` с `static-s3.mtt.xyz/app-v/s01/js/`.
5. Транспорт Telegram `startapp` доставляет payload Mini App **бота-получателя**, а не открывает обычную страницу `mtt.xyz/?i=...`. Документация: https://core.telegram.org/api/bots/webapps

**Вывод:** корректная регистрация игрового профиля через named Mini App не гарантирует наличие нашей реферальной атрибуции. Повторный визит по `?i=...` после создания профиля не доказан как способ привязать уже существующего пользователя.

## Исправление, применённое в STAGING

- Первая кнопка для новичков — собственная реферальная ссылка `?i=ba434b5a` (официальный веб-путь).
- Native Play Now — вторичная кнопка, явно помеченная только для существующих аккаунтов; её запуска нельзя считать приглашением.
- В публичной диагностике GitHub Actions отдельно вычисляется missingAffiliateAtGameLaunch, и фиксируется `UNVERIFIED_BY_PLATFORM`, а не успешный referral.
- Ни регистрация через неподтверждённый API, ни денежные операции, ни обходы SSO не выполняются.
- Production бот и production финансовые воркеры не меняются.

## Проверка с минимальным риском

1. Для **нового и согласившегося тестового пользователя**, не имевшего аккаунта MTT SPORTS, первым действием открыть `https://mtt.xyz/?i=ba434b5a`.
2. Зарегистрироваться в MTT SPORTS официально поддерживаемым способом; не использовать чужой Play Now **до** завершения регистрации.
3. Проверить в кабинете пригласившего вкладку «Моё приглашение» и точный профиль пользователя, не ориентируясь на нулевой доход.
4. Если список пуст даже в таком случае, запросить у поддержки MTT SPORTS выяснение reason code на сервере. Не регистрировать массовые тестовые аккаунты.
5. На проверку уже зарегистрированного пользователем аккаунта запросить у поддержки возможность легальной ретроактивной привязки по коду.

## Вопросы оператору MTT SPORTS

- Поддерживает ли именованное `@MTTSPORTS_bot/MTTSPORTS` приложение реферальный параметр `startapp` / `params.i` / `referer`? Какой формат официально разрешён?
- Когда фиксируется реферал: при открытии `?i`, первом SSO, завершении регистрации или первой оплаченной активности?
- Требуется ли посетить `?i` в том же Telegram WebView до создания TelegramUser аккаунта?
- Есть ли партнёрский SDK/API с проверкой `inviterId`, `inviteeId`, статуса привязки и выплаты?
- Можно ли исправить привязку профиля, уже созданного без кода?
- Является ли `@MTTSPORTS_bot` официальным каналом платформы и вправе ли сторонние боты открывать его named Mini App?

## Примечание о доходах

Реферальная программа MTT SPORTS связана с расходами на турниры/магазин; комиссия нашего будущего обменника — отдельная бизнес-модель, которая не следует автоматически из реферального соглашения. Оба вида дохода требуют проверенных начислений и правил сервиса.
