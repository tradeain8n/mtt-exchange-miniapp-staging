🔗 Привязка через наш Email CLI

Для проверки существующего аккаунта отправь в чате GiftMutant команду /mttlink. Затем на TV Box запусти mttsports-safe auth email.

Если CLI уже показал EVM-адрес и ожидает код привязки, повторно запрашивать письмо не нужно: получи свежий /mttlink и введи его в терминале. Иначе код из письма вводится только в локальном CLI; срок привязки — 10 минут.

📬 Для уведомления о новом письме используй /mttmail в GiftMutant. Этот режим читает только заголовки и требует отдельного Gmail OAuth-доступа на TV Box.

Партнёрский вход MTT SPORTS без CLI появится после согласования официального SSO/API с платформой. Telegram-вход сам по себе не подтверждает игровой EVM-адрес.

Вход на внешнем сайте ещё не доказывает связь аккаунтов. Мы не читаем cookies, не получаем приватные ключи и не включаем вывод средств из игрового кошелька.
